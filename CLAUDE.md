# Правила для Claude в этом проекте

## О проекте
- Арканоид на **Unity 6.6 (6000.6.9f1)**, шаблон Universal 2D (URP). Это первый шаг плана обучения Unity.
- Владелец учится: объясняй **на русском**, простыми словами, без лишней теории.
- Описание кода — в `README.md`. Обновляй его, когда меняется устройство проекта.

## Git — главное правило
- Владелец изучает изменения **через историю Git на GitHub**. Поэтому:
  - **один коммит = одно понятное изменение** (не сваливать всё в один коммит);
  - сообщение коммита **на русском**: первая строка — что сделано, ниже 2–4 строки — зачем и как это работает;
  - перед коммитом показывать, какие файлы меняются.
- Не коммитить служебные папки Unity (`Library/`, `Temp/`, `Logs/`, `UserSettings/`) — они в `.gitignore`.
- `push` на GitHub — после каждого законченного шага.

## Код
- Скрипты — в `Assets/Scripts`, комментарии на русском.
- Ввод — только новая **Input System** (`UnityEngine.InputSystem`): в проекте включён только новый ввод, старый `Input.GetKey` выдаст ошибку.
- Unity 6: у `Rigidbody2D` скорость — `linearVelocity` (не `velocity`).
- Unity сам создаёт `.meta`-файлы для новых файлов — их тоже нужно коммитить.
