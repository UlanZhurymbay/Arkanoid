# Арканоид (Unity 6.6)

Первая игра на Unity из плана обучения: мяч, ракетка, кирпичи, физика.

## Как запустить
1. Открыть папку проекта через Unity Hub (версия редактора 6000.6.9f1).
2. Нажать **▶ Play**.

Управление: **Пробел / клик** — запустить мяч, **← → / A D / мышь** — ракетка, **Esc / P** — пауза.

## Как устроен код (`Assets/Scripts`)

Сейчас вся игра создаётся **из кода** при нажатии Play — на сцене ничего не расставлено вручную.

| Файл | Что делает |
|---|---|
| `GameBootstrap.cs` | Точка входа. Атрибут `[RuntimeInitializeOnLoadMethod]` заставляет Unity вызвать метод после загрузки сцены — он создаёт объект `GameManager`. |
| `GameManager.cs` | «Мозг» игры: настраивает камеру, строит стены, ракетку, мяч и кирпичи; хранит очки, жизни, уровень; переключает состояния (Ready → Playing → LevelComplete / GameOver); рисует интерфейс через `OnGUI`. |
| `Paddle.cs` | Ракетка. Читает клавиатуру и мышь (новая Input System), двигается через кинематический `Rigidbody2D` в `FixedUpdate`. |
| `Ball.cs` | Мяч. Пока «прилеплен» — едет за ракеткой. После запуска физика Unity (`Rigidbody2D` + `CircleCollider2D`) считает отскоки, а скрипт держит скорость постоянной и задаёт угол отскока от ракетки. |
| `Brick.cs` | Кирпич: число ударов, очки, цвет. При разрушении сообщает `GameManager`. |
| `SpriteFactory.cs` | Рисует квадрат и круг в памяти — картинки не нужны. |

### Главные идеи Unity, которые здесь используются
- **GameObject** — любой объект в игре (ракетка, мяч, кирпич).
- **Component** — «способность» объекта: `SpriteRenderer` (видно), `BoxCollider2D` (твёрдый), `Rigidbody2D` (подчиняется физике), свои скрипты.
- **MonoBehaviour** — базовый класс скриптов. Unity сам вызывает `Awake`, `Update` (каждый кадр), `FixedUpdate` (каждый шаг физики), `OnCollisionEnter2D` (столкновение).
